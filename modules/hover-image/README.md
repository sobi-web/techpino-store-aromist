# Aromist Hover Image – تصویر هاور محصول

وقتی موس روی باکس محصول می‌رود، یک تصویر اختصاصی (رایحه، نت‌ها، گروه بویایی) جای عکس اصلی نمایش داده می‌شود.

## نصب
1. فایل `dist/aromist-hover-image-1.1.0.zip` را از «افزونه‌ها ← افزودن ← بارگذاری» نصب و فعال کنید.
2. در ویرایش هر محصول، باکس **«تصویر هاور (نت‌ها و گروه بویایی)»** در ستون کناری است. تصویر را انتخاب کنید و محصول را به‌روزرسانی کنید.
3. در لیست محصولات، ستون **«هاور»** نشان می‌دهد کدام محصول تصویر هاور دارد.

## اضافه کردن به باکس محصول
### Loop Grid المنتور یا Listing Grid جت‌انجین
1. قالب آیتم لوپ المنتور / لیستینگ جت‌انجین محصولات را باز کنید.
2. ویجت تصویر فعلی محصول را حذف کنید و ویجت **«تصویر محصول + هاور (آرومیست)»** را جایش بگذارید (در لیستینگ جت‌انجین کنار ویجت‌های جت هم هست).
3. تنظیمات: سایز تصویر، **عرض تصویر** (px / % / vw، جدا برای دسکتاپ/تبلت/موبایل)، نسبت ابعاد، هاور روی «کل باکس» یا «فقط تصویر»، افکت، رفتار در موبایل، و جایگزین از گالری.

**لینک:** «لینک به محصول» به‌طور پیش‌فرض خاموش است و ویجت هیچ تگ `<a>` نمی‌سازد؛ چون کانتینر باکس معمولاً خودش لینک دارد و لینک تو در تو باعث می‌شود مرورگر ساختار آیتم را به هم بریزد. فقط اگر باکس شما لینک ندارد روشنش کنید.

**جت‌انجین:** محصول از خود آیتم لیستینگ خوانده می‌شود؛ هم Query از نوع Posts و هم WC Product Query. اگر لیستینگ «متغیر»ها را نشان دهد، تصویر هاور محصول مادر استفاده می‌شود.

فقط کافی است قالب آیتم را یک‌بار عوض کنید؛ همه‌ی جاهایی که از آن قالب استفاده می‌کنند (فروشگاه، دسته‌ها، اسلایدرها) درست می‌شوند.

### جاهای دیگر (شورت‌کد)
```
[aromist_hover_image]
[aromist_hover_image id="123" width="180px" effect="zoom" trigger="image" ratio="1/1" mobile="none" fallback="gallery" link="yes"]
```
بدون `id` از محصول فعلی لوپ استفاده می‌شود.

## رفتار
- **دسکتاپ:** با هاور موس (یا فوکوس صفحه‌کلید) تصویر هاور با افکت ظاهر می‌شود.
- **موبایل / تبلت:** دکمه‌ی ⓘ روی تصویر؛ با لمس آن تصویر باز/بسته می‌شود (به صفحه‌ی محصول نمی‌رود).
- **سرعت:** تصویر هاور فقط وقتی موس وارد باکس شد یا دکمه لمس شد دانلود می‌شود؛ روی سرعت بارگذاری صفحه اثری ندارد.
- آیتم‌هایی که با Ajax اضافه می‌شوند (Load more، فیلترهای JetSmartFilters) هم بدون تنظیم اضافه کار می‌کنند.

## نکات تصویر
- نسبت ابعاد مثل عکس اصلی محصول (مثلاً هر دو مربع ۸۰۰×۸۰۰).
- WebP، ترجیحاً زیر ۱۰۰ کیلوبایت.
- متن درشت؛ باکس محصول کوچک‌تر از تصویر اصلی نمایش داده می‌شود.
- متن جایگزین (Alt) تصویر را در کتابخانه‌ی رسانه بنویسید؛ اگر خالی باشد «رایحه، نت‌ها و گروه بویایی {نام محصول}» استفاده می‌شود.

## برای توسعه‌دهنده
- متا: `_aromist_hover_image` (شناسه‌ی پیوست).
- فیلتر `aromist_hover_image_id( $id, $product_id, $with_fallback )` برای استفاده از منبع دیگر (مثلاً فیلد JetEngine).
- فیلتر `aromist_hover_image_current_product_id( $id )` اگر در قالبی خاص محصول باید از جای دیگری خوانده شود.
- ساخت zip: `bin/build-zip.sh`
