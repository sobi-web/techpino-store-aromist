# Aromist Discovery Set — دیسکاوری ست

افزونه‌ی ووکامرس برای فروش **پک ۴ عطر ۱۰ میلی** (دیسکاوری ست):
- **ست‌های آماده** که در پیشخوان ساخته می‌شوند، با صفحه‌ی اختصاصی؛
- **ست اختصاصی** که مشتری خودش در صفحه‌ی «ست خودت را بساز» می‌سازد و می‌تواند در **«ست‌های من»** (پنل کاربری) ذخیره کند.

هر ست فروخته‌شده از **مخزن میلی‌لیتری** هر ۴ عطر (افزونه‌ی «موجودی حجمی») و از **موجودی جعبه** کم می‌کند.

- نسخه: **0.3.4** — ووکامرس 9.0+ (تست‌شده روی 11.1.2)، وردپرس 6.5+ (تست‌شده روی 7.1.3)، PHP 7.4+ (تست‌شده روی 8.1)
- تست‌شده روی **staging خام** (کپی دست‌نخورده‌ی بک‌آپ ۲۲ مهر ۱۴۰۵، همه‌ی افزونه‌ها، PHP 8.1 + ionCube مثل هاست)
- **نیازمند Aromist Volume Stock نسخه‌ی 1.1.0 یا بالاتر** (برای «موجودی نامحدود» عطرها: 1.2.0)
- سازگار با HPOS؛ سبد و تسویه‌ی کلاسیک (اسنیپت‌های `[aromist_cart]` و `[aromist_checkout]`)، مینی‌کارت و پنل کاربری تک‌پینو
- سند فنی و تصمیم‌ها: [`docs/SPEC.md`](docs/SPEC.md)

## چه چیزهایی دارد

| بخش | توضیح |
|---|---|
| **ست آماده** | نوع محصول «دیسکاوری ست» با تب «محتوای ست» (۴ عطر با جستجو، قیمت خودکار یا ثابت، پیش‌نمایش قیمت و تعداد قابل فروش). |
| **صفحه‌ی اختصاصی هر ست** | گالری روی پس‌زمینه‌ی جدا با سایه (کاور + گالری انتخابی، یا اگر گالری خالی باشد عکس ۴ عطر؛ تصویر بریده نمی‌شود)، توضیح کوتاه، «عطرهای ۱۰ میل داخل این ست»، قیمت با تخفیف و «سود شما»، افزودن به سبد با انیمیشن پرواز ویال‌ها به سبد، «این ست را شخصی کن»، **تب هر عطر با همه‌ی اطلاعات صفحه‌ی محصول** (تصاویر گالری عطر، برند، نام انگلیسی، گروه بویایی، توضیح، طبع، فصل، حال و هوا، پخش بو، ماندگاری، موقعیت استفاده — هر کدام حداکثر ۲ مقدار —، نت‌های اولیه/میانی/پایانی — هر سطح ۵ نت و بقیه با «نمایش بیشتر»؛ گروه بویایی، نت‌ها و مقدارهای دارای صفحه به صفحه‌ی خودشان لینک‌اند)، توضیحات ست، **نظرات با امتیاز** (همان «استودیو نظرات نقطه» صفحه‌ی محصول)، ست‌های دیگر، نوار خرید چسبان در موبایل. |
| **صفحه‌ی دیسکاوری ست‌ها** | معرفی، «چطور کار می‌کند»، کارت همه‌ی ست‌های آماده و کارت «ست خودت را بساز». |
| **ست خودت را بساز** | فقط عطرهایی که مدیر انتخاب کرده؛ جستجو (نام، برند، نت) و چهار فهرست انتخابی **جنسیت، فصل، گروه بویایی، حال و هوا و شخصیت** (با تعداد عطر هر گزینه که با بقیه‌ی انتخاب‌ها به‌روز می‌شود، و «حذف فیلترها»)، پنجره‌ی «جزئیات» هر عطر، جعبه‌ی ۴ خانه با قیمت زنده، افزودن به سبد، ذخیره در «ست‌های من». در موبایل: نوار پایین + کشوی «ست تو». |
| **ست‌های من** | تب جدید پنل کاربری: ست‌های ذخیره‌شده با قیمت لحظه‌ای، «خرید»، «ویرایش»، «حذف». |
| **دو تخفیف** | یک درصد برای ست‌های آماده، یک درصد برای ست‌های اختصاصی؛ هر وقت بخواهید از تنظیمات عوض می‌شود. |
| **موجودی** | کسر از مخزن میلی هر عطر (با هدررفت) و یک جعبه؛ رزرو هنگام پرداخت؛ برگشت هنگام لغو/مرجوعی. |

## نصب روی سایت اصلی

> **اول روی staging** (`staging-raw` — http://localhost:8891) همه‌چیز را ببینید. قبل از نصب روی سایت اصلی **بک‌آپ کامل** بگیرید.

1. **موجودی حجمی را دوباره فعال کنید.** روی سایت اصلی پوشه‌ی این افزونه `aromist-volume-stock-off` نام‌گذاری شده و غیرفعال است. فایل `aromist-volume-stock/dist/aromist-volume-stock-1.1.0.zip` را نصب و فعال کنید.
2. **برای هر عطری که در ست‌ها می‌آید، موجودی حجمی را فعال و موجودی مخزن (میل) را وارد کنید** («موجودی حجمی ← افزودن»). فقط این عطرها در ست قرار می‌گیرند.
3. `dist/aromist-discovery-set-0.3.0.zip` را از «افزونه‌ها ← افزودن ← بارگذاری» نصب کنید (جایگزین نسخه‌ی 0.1.1).
4. یک بار «دیسکاوری ست ← تنظیمات» را باز کنید. افزونه این‌ها را می‌سازد (برای مشتری دیده نمی‌شوند):
   - محصول خصوصی **«جعبه دیسکاوری ست»** (موجودی اولیه **صفر**)
   - محصول خصوصی و سیستمی **«دیسکاوری ست اختصاصی»** (حامل ست‌های مشتری؛ حذفش نکنید)
   - دو برگه به‌صورت **پیش‌نویس**: «دیسکاوری ست‌ها» (`/discovery-sets/`) و «ساخت دیسکاوری ست اختصاصی» (`/build-discovery-set/`)
5. **موجودی جعبه** را وارد کنید و تخفیف‌ها را تنظیم کنید.
6. «دیسکاوری ست ← عطرهای ست اختصاصی»: عطرهای سازنده را تیک بزنید.
7. ست‌های آماده را بسازید (اول پیش‌نویس، با «پیش‌نمایش» ببینید، بعد منتشر کنید).
8. دو برگه را **منتشر** کنید و لینکشان را به منوی سایت اضافه کنید.

## تنظیمات

«دیسکاوری ست ← تنظیمات»:

| بخش | توضیح |
|---|---|
| **هزینه‌ی بسته‌بندی هر ست** | به قیمت هر ست اضافه می‌شود (پیش‌فرض صفر). |
| **جعبه** | هر ست فروخته‌شده یک عدد از این جعبه کم می‌کند (یا «بدون شمارش جعبه»). |
| **تخفیف ست‌های آماده (٪)** | از جمع قیمت ۴ عطرِ ست‌های پیشخوان کم می‌شود. |
| **تخفیف ست‌های اختصاصی (٪)** | از جمع قیمت ۴ عطرِ ست‌هایی که مشتری می‌سازد (و ست‌های آماده‌ای که «شخصی» می‌کند) کم می‌شود. |
| **گرد کردن** | قیمت‌ها به نزدیک‌ترین مضرب این عدد گرد می‌شوند (پیش‌فرض ۱۰۰۰). |
| **حداکثر «ست‌های من»** | تعداد ست‌هایی که هر مشتری می‌تواند ذخیره کند (پیش‌فرض ۲۰). |
| **صفحه‌ها** | برگه‌ی دیسکاوری ست‌ها (آدرس ست‌ها زیر آدرس همین برگه است) و برگه‌ی سازنده. |
| **صفحه‌ی اختصاصی هر ست** | روشن (پیش‌فرض): طراحی اختصاصی افزونه. خاموش: قالب محصول المنتور. |
| **نمایش در فروشگاه** | خاموش (پیش‌فرض): ست‌ها فقط در صفحه‌ی دیسکاوری ست‌ها و جستجو؛ در فروشگاه و دسته‌های عطر نمی‌آیند. |
| **جعبه‌ها** | موجودی هر جعبه (افزایش / کاهش / مقدار دقیق) و ساخت جعبه‌ی جدید. |
| **وضعیت سیستم** | مدیریت موجودی ووکامرس، «نگه‌داشتن موجودی»، نسخه‌ی موجودی حجمی. همه باید ✓ باشند. |

> **مهم:** تا موجودی جعبه را وارد نکنید، همه‌ی ست‌ها «ناموجود» نمایش داده می‌شوند.

## عطرهای ست اختصاصی

«دیسکاوری ست ← عطرهای ست اختصاصی»: فهرست همه‌ی عطرهای متغیر، با وضعیت موجودی حجمی و قیمت ۱۰ میل. فقط تیک‌خورده‌ها در صفحه‌ی سازنده می‌آیند. عطری را که موجودی حجمی ندارد نمی‌توان تیک زد (دلیلش نوشته شده و لینک «فعال‌سازی موجودی حجمی» کنارش است).
همین تیک در صفحه‌ی ویرایش هر عطر هم هست («موجودی انبار» ← «دیسکاوری ست اختصاصی»).

اگر عطری را از سازنده بردارید: در «ست‌های من» ستِ شامل آن با توضیح «دیگر ارائه نمی‌شود» نشان داده می‌شود و «خرید»ش خاموش است تا مشتری عطر دیگری جایگزین کند؛ اگر در سبد باشد با پیام حذف می‌شود. ست‌های آماده به این فهرست وابسته نیستند.

## ساخت ست آماده

1. «دیسکاوری ست ← افزودن ست» (نوع محصول از قبل «دیسکاوری ست» است).
2. نام، **توضیح کوتاه** (بالای صفحه‌ی ست)، **توضیحات کامل** (بخش «درباره‌ی این ست») و **تصویر محصول** (کاور ست).
3. **گالری**: اختیاری. خالی بماند ← عکس ۴ عطر (با عوض شدن عکس عطر، خودکار عوض می‌شود). تصویر اضافه کنید ← همان تصاویر.
4. تب «محتوای ست»: ۴ عطر (فقط عطرهای دارای موجودی حجمی در جستجو می‌آیند؛ ترتیب = ترتیب نمایش)، قیمت «خودکار» یا «ثابت»، و پیش‌نمایش قیمت و تعداد قابل فروش.
5. «انتشار». ست خودکار در دسته‌ی «دیسکاوری ست» قرار می‌گیرد و آدرسش `/discovery-sets/نام-ست/` است.

«دیسکاوری ست ← ست‌های آماده» همه‌ی ست‌ها را با قیمت و تعداد قابل فروش نشان می‌دهد.

## صفحه‌ها

| صفحه | آدرس | محتوا |
|---|---|---|
| آرشیو دیسکاوری ست‌ها | `/product-category/discovery-set/` و زیردسته‌ها (`…/discovery-set-for-man/`، `…/discovery-set-for-woman/`) | قالب آرشیو المنتور (بالای صفحه طراحی خودتان) + شورت‌کد `[aromist_discovery_sets]` |
| هر ست آماده | `/discovery-sets/نام-ست/` | قالب اختصاصی افزونه (هدر و فوتر سایت حفظ می‌شود) |
| ساخت ست | `/build-discovery-set/` | بالای صفحه طراحی خودتان + شورت‌کد `[aromist_set_builder]` |
| ست‌های من | `/my-account/my-sets/` | تب پنل کاربری تک‌پینو |

**شورت‌کدها** (در ویجت «کد کوتاه» المنتور؛ عرض و فاصله‌ی کناری را بخش المنتور تعیین می‌کند):

| شورت‌کد | کار |
|---|---|
| `[aromist_discovery_sets]` | ست‌های آماده. در قالب آرشیو دسته‌ی «دیسکاوری ست» با کوئری ووکامرس کار می‌کند: در «دیسکاوری ست» همه‌ی ست‌ها، در «دیسکاوری ست مردانه» / «زنانه» فقط ست‌های همان دسته. پس یک قالب آرشیو برای هر سه دسته کافی است (یا برای هر کدام قالب جدا با همین شورت‌کد). |
| `[aromist_discovery_sets category="discovery-set-for-man"]` | فقط یک دسته (نامک، نام یا شناسه) — برای برگه‌های معمولی. |
| گزینه‌ها | `columns="3"` (ستون در صفحه‌ی پهن، ۱ تا ۴)، `limit="6"`، `builder_card="no"` (بدون کارت «ست خودت را بساز»)، `hero="yes"` (معرفی خود افزونه در بالا). |
| `[aromist_set_builder]` | ساخت ست اختصاصی (`hero="yes"` = معرفی خود افزونه در بالا). |

کارت‌ها اندازه‌شان را از عرض جای خودشان می‌گیرند (container query)، نه عرض صفحه: زیر ۵۶۰ پیکسل کارت افقی (عکس کنار اطلاعات)، بعد ۲ / ۳ / ۴ ستون. در سازنده هم کارت عطرها در موبایل افقی‌اند.

لینک «دیسکاوری ست‌ها» (مسیر صفحه‌ی هر ست و «همه‌ی ست‌ها») به آرشیو دسته‌ی «دیسکاوری ست» می‌رود؛ در تنظیمات می‌شود برگه‌ی افزونه را انتخاب کرد. برگه‌ی «دیسکاوری ست‌ها» را **حذف نکنید** (آدرس ست‌ها زیر نامک آن است؛ پیش‌نویس بودنش اشکالی ندارد).

همه‌ی صفحه‌ها موبایل‌محورند و در ۳۲۰، ۳۷۵، ۷۶۸، ۱۰۲۴ و ۱۴۴۰ پیکسل بررسی شده‌اند (بدون اسکرول افقی). نوارهای ثابت پایین صفحه خودشان را بالای نوار پایین سایت و کنار دکمه‌ی پشتیبانی قرار می‌دهند.

قالب‌ها در پوسته قابل بازنویسی‌اند: `yourtheme/woocommerce/discovery-sets/{archive,single,builder,card,perfume,my-sets}.php`.

## ست‌های من (پنل کاربری)

- مشتری واردشده در سازنده، ست کامل را با نام دلخواه (اختیاری؛ وگرنه «ست شماره N») **ذخیره** می‌کند. مهمان دکمه‌ی «برای ذخیره‌ی ست وارد شو» را می‌بیند و بعد از ورود به سازنده برمی‌گردد (انتخاب‌هایش می‌ماند). مهمان بدون ورود هم می‌تواند ست بسازد و بخرد.
- همان ۴ عطر با ترتیب دیگر، ست تکراری نمی‌سازد.
- **نام ست در سبد و سفارش:** هر کسی (مهمان یا واردشده) در سازنده می‌تواند برای ستش نام بگذارد. ست با همان نام در سبد، مینی‌کارت، تسویه، سفارش و ایمیل‌ها ثبت می‌شود و دیگر «دیسکاوری ست اختصاصی» نوشته نمی‌شود (بدون نام، همان «دیسکاوری ست اختصاصی»). «خرید» از «ست‌های من» هم با نام ذخیره‌شده‌ی ست است. همان ست با دو نام متفاوت دو ردیف جدا در سبد است.
- در پنل: کارت هر ست با ۴ عطر، قیمت لحظه‌ای (با تخفیف ست‌های اختصاصی)، **خرید** (افزودن به سبد)، **ویرایش** (سازنده با همان ست؛ «ذخیره‌ی تغییرات») و **حذف**.

## قیمت

قیمت هر عطر = قیمت فعال (با حراج) متغیر ۱۰ میل آن (اگر نداشت: قیمت هر میلِ کوچک‌ترین حجم × ۱۰).

قیمت ست = جمع ۴ عطر × (۱ − تخفیف) + هزینه‌ی بسته‌بندی، گردشده. تخفیف ست آماده و ست اختصاصی جداست. قیمت قبل از تخفیف خط‌خورده نمایش داده می‌شود و «سود شما» در صفحه‌ی ست، سبد و مینی‌کارت درست است. قیمت در سبد همیشه لحظه‌ای است.

## سبد، سفارش و موجودی

| اتفاق | اثر |
|---|---|
| افزودن به سبد / تغییر تعداد | میل همه‌ی آیتم‌های سبد از هر عطر (ست‌ها + شیشه‌های معمولی) نباید از «مخزن − رزرو دیگران» بیشتر شود؛ برای جعبه هم همین‌طور. وگرنه پیام فارسی. |
| نمایش در سبد، تسویه، مینی‌کارت، پنل کاربری، سفارش پیشخوان، ایمیل‌ها | «حجم هر عطر: ۱۰ میل» و «عطرها: …». |
| ورود به درگاه | سهم ست‌ها از مخزن‌ها و جعبه رزرو می‌شود. |
| پرداخت / «در حال انجام» | `(۱۰ + هدررفت) × تعداد` از هر مخزن و `تعداد` از جعبه کم می‌شود؛ در تاریخچه‌ی موجودی حجمی و یادداشت سفارش ثبت می‌شود. |
| لغو / ناموفق / مرجوعی با «بازگرداندن به انبار» | دقیقاً همان مقدار برمی‌گردد. |
| تمام شدن یک عطر یا جعبه | ست «ناموجود» می‌شود؛ در سازنده آن عطر «ناموجود» است. |

در صفحه‌ی سفارش پیشخوان، زیر هر ست کادر **«بسته‌بندی»** هست: چند ست × ۴ ویال ۱۰ میلی، میل هر عطر (با هدررفت) و مقدار کسرشده.

**تست کامل روی staging خام (۲۳ مهر ۱۴۰۵):** سفارش واقعی از سبد و تسویه‌ی اختصاصی سایت با یک ست آماده، یک ست اختصاصی و یک شیشه‌ی ۱۰ میل: مخزن‌ها دقیقاً ۲۲/۱۱ میل و جعبه ۲ عدد کم شد؛ با لغو سفارش همه برگشت.

## نکات مهم و محدودیت‌ها

- **غیرفعال کردن افزونه:** قبل از غیرفعال کردن، ست‌ها را پیش‌نویس کنید؛ وگرنه ووکامرس آن‌ها را محصول ساده با قیمت ذخیره‌شده می‌بیند و بدون برداشت از مخزن‌ها فروخته می‌شوند.
- فقط عطرهای دارای **موجودی حجمی** در ست قرار می‌گیرند. هر عطر فقط یک بار در یک ست. همه‌ی ست‌ها ۴ × ۱۰ میل‌اند.
- **عطر با موجودی حجمی «نامحدود»** (موجودی حجمی 1.2.0: هر عطر جدید تا وقتی مخزنش تعیین نشده): در ست‌ها بدون محدودیت فروخته می‌شود و از آن کم نمی‌شود (در کادر «بسته‌بندی» سفارش: «موجودی نامحدود»). اگر همه‌ی حجم‌هایش را دستی «ناموجود» کنید، در ست‌ها و سازنده هم ناموجود است. با تعیین موجودی مخزن، مثل بقیه محدود می‌شود.
- سبد و تسویه‌ی **بلوکی** ووکامرس پشتیبانی نمی‌شوند (سایت از نسخه‌ی کلاسیک استفاده می‌کند).
- **«خبرم کنید» (LetMeKnow):** این افزونه روی ذخیره‌ی محصول جدید بدون شناسه و روی هر ذخیره‌ی محصول در WP-CLI خطا می‌دهد، و در اطلاع‌رسانی «موجود شد» قیمت را از دیتابیس می‌خواند. دیسکاوری ست محصولاتش را با شناسه می‌سازد و از 0.3.0 قیمت ست را **قبل** از ذخیره می‌نویسد (بدون این کار، ستی که اول ناقص ذخیره شده بود هنگام «موجود» شدن نیمه‌کاره ذخیره می‌شد و «ناموجود» می‌ماند). تست‌ها باید از طریق وب اجرا شوند.
- **نظرات ست:** اگر «استودیو نظرات نقطه» فعال و لایسنس‌دار باشد همان بخش نظرات صفحه‌ی محصول نمایش داده می‌شود، وگرنه فرم نظرات خود ووکامرس.
- اگر «نگه‌داشتن موجودی» ووکامرس صفر باشد، رزرو انجام نمی‌شود.

## اطلاعات فنی

**مدل داده** — جزئیات در [`docs/SPEC.md`](docs/SPEC.md) بخش ۴.

| کجا | کلید | معنی |
|---|---|---|
| محصول ست | `_ads_components`، `_ads_component` | ۴ عطر (فهرست مرتب + یک ردیف برای هر عطر) |
| محصول ست | `_ads_volumes`، `_ads_default_volume`، `_ads_price_mode`، `_ads_fixed_prices` | حجم، حالت قیمت، قیمت ثابت |
| محصول «ست اختصاصی» | `_ads_is_custom = yes` | محصول سیستمی |
| عطر | `_ads_in_builder = yes` | در سازنده ارائه می‌شود |
| جعبه | `_ads_box = yes` | محصول خصوصی با موجودی ووکامرس |
| کاربر | `_ads_saved_sets` | «ست‌های من»: `[{ id, name, c: [۴ عطر], created, updated }]` |
| آیتم سبد | `ads = { v, c }` | حجم و ۴ عطر |
| آیتم سفارش | `حجم هر عطر`، `عطرها`، `_ads_set`، `_ads_reduced`، `_ads_refunded` | نمایش + عکس لحظه‌ی خرید و برداشت‌ها |
| گزینه | `ads_settings` | تنظیمات (`discount`، `custom_discount`، `max_saved_sets`، …) |

**اطلاعات عطر** (`ADS_Perfume_Info`): ویژگی‌های قابل‌نمایش محصول (به‌جز حجم)، متای `english_title`، برند (`product_brand`)، تصاویر گالری، و ارتباط‌های جت‌انجین: «گروه بویایی محصول» (پست‌تایپ `olfactory-families` ← محصول) و «نت اولیه / میانی / پایانی» (محصول ← پست‌تایپ `notes`). ارتباط‌ها از روی اشیا و نامشان پیدا می‌شوند؛ با فیلتر `ads_perfume_relations` قابل تعیین‌اند. لینک‌ها: صفحه‌ی هر نت و گروه بویایی، و صفحه‌ی مقدار ویژگی‌هایی که آرشیو دارند (مثل `/atmosphere-and-characters/…`). فیلترها: `ads_spec_max_values` (۲)، `ads_notes_shown` (۵).

**فیلترهای سازنده** (`ADS_Pages::filter_sources()`): جنسیت = دسته‌های بالایی «عطر مردانه / زنانه / یونیسکس»، فصل = زیردسته‌های «فصل ها» (مثل صفحه‌ی محصول؛ اگر نباشد ویژگی `pa_for-the-season`)، گروه بویایی = ارتباط جت‌انجین، حال و هوا = ویژگی `pa_atmosphere-and-characters`. با فیلترهای `ads_builder_filter_sources` و `ads_builder_filters` قابل تغییرند.

**هوک‌ها**
- `ads_set_size`، `ads_allowed_volumes`، `ads_price_breakdown`، `ads_gallery_image_ids`، `ads_custom_product_redirect`
- `ads_perfume_info` (اطلاعات هر عطر)، `ads_perfume_relations` (شناسه‌ی ارتباط‌های جت‌انجین)، `ads_hidden_spec_attributes` (ویژگی‌هایی که نمایش داده نمی‌شوند؛ پیش‌فرض `pa_volume`)، `ads_reviews_html`
- `ads_settings_saved` (action)

**AJAX** (wc-ajax): `ads_add_to_cart` (افزودن ست؛ فرگمنت‌های ووکامرس را برمی‌گرداند)، `ads_save_set` و `ads_delete_set` (ست‌های من، نانس `ads_saved_sets`).

**API**
- `ADS_Cart::add_set( $product_id, $volume, $components = null, $qty = 1 )`
- `ADS_Saved_Sets::save( $user_id, $components, $name = '', $id = '' )`، `::all()`، `::delete()`
- `ADS_Set::builder_ids()`، `::in_builder()`، `::set_in_builder()`
- `ADS_Pricing::breakdown( $components, $volume, $product = null )`
