# Aromist Season Filter – فیلتر AJAX کاروسل محصولات

ویجت المنتور «**فیلتر AJAX کاروسل (آرومیست)**»: چند دکمه (پیش‌فرض: خنک / گرم / چهار فصل) بالای یک **Loop Carousel** که با کلیک، اسلایدهای همان کاروسل را بدون ری‌لود عوض می‌کند.
جایگزین Nested Tabs با ۳ کاروسل پنهان؛ به‌جای ۹ کاروسل در HTML فقط یکی (حالت پیش‌فرض) رندر می‌شود.

نیازمندی‌ها: وردپرس ۶.۴+، PHP 7.4+، ووکامرس، المنتور و المنتور پرو (Loop Carousel).

## چطور کار می‌کند

1. کاروسل هدف به یکی از دو راه پیدا می‌شود:
   - **با شناسه (پیشنهادی):** روی Loop Carousel در تب Advanced فیلد «CSS ID» را پر کنید (مثلاً `men-carousel`) و همان را در ویجت فیلتر در «شناسهٔ کاروسل هدف» بنویسید. ویجت فیلتر را می‌توانید **هر جای همان صفحه** بگذارید (کنار عنوان، داخل هدر بخش، …).
   - **بدون شناسه:** ویجت فیلتر را داخل همان کانتینرِ کاروسل بگذارید؛ اولین Loop هم‌کانتینر خودکار هدف می‌شود.
2. اولین رندر صفحه فقط برای **دکمهٔ پیش‌فرض** است. ویجت فیلتر «تنها منبع حقیقت» ترم فصل است؛ ترم فصلی که روی خود کاروسل ست شده نادیده گرفته می‌شود (ترم دسته‌بندی/برند و … روی کاروسل می‌ماند).
3. کلیک روی دکمه → یک درخواست GET به `admin-ajax.php?action=asf_slides` با (شناسهٔ سند، شناسهٔ ویجت فیلتر، شمارهٔ دکمه). سرور کاروسل هدف و ترم را از داده‌ی ذخیره‌شدهٔ المنتور می‌خواند (چیزِ دلخواه رندر نمی‌شود) و خود ویجت کاروسل را با همان قالب کارت رندر می‌کند؛ پس قیمت، تخفیف (aromist-deals)، حجم‌ها و تصویر هاور عیناً مثل اول صفحه‌اند.
4. جاوااسکریپت اسلایدهای Swiper موجود را عوض می‌کند (loop را دوباره می‌سازد؛ اگر اسلاید کمتر از تعداد نمایش بود loop را خاموش می‌کند).

## کش و سرعت

- پاسخ هر دکمه ۱۰ دقیقه با ترنزینت کش می‌شود و با ذخیرهٔ محصول، تغییر موجودی، ویرایش ترم یا ذخیرهٔ سند المنتور خودکار باطل می‌شود. فیلترها: `asf_cache_ttl` (ثانیه)، `asf_browser_max_age`.
- در مرورگر جواب‌ها در حافظه می‌مانند؛ با hover/touch/focus روی یک دکمه همان دکمه، و بعد از اولین جواب بقیهٔ دکمه‌ها (در زمان بیکاری) پیش‌دریافت می‌شوند.
- استایل‌های درون‌خطیِ تکراریِ کارت‌ها در پاسخ حذف می‌شوند.

## نصب روی سایت

1. پلاگین را از `dist/aromist-season-filter-<نسخه>.zip` نصب و فعال کنید.
2. در المنتور صفحهٔ اصلی: Tabs را حذف کنید و کاروسل اولِ تب «خنک» را بیرون از تب‌ها بگذارید.
3. روی کاروسل: Advanced ← CSS ID را بنویسید (مثلاً `men-carousel`). در Query ← Include ← Term فقط **دسته‌بندی** (مثلاً «عطر مردانه») را بگذارید، نه ترم فصل.
4. ویجت «فیلتر AJAX کاروسل» را هر جا می‌خواهید بکشید (مثلاً کنار عنوان بخش) و در «شناسهٔ کاروسل هدف» همان `men-carousel` را بنویسید. بعد صفحه را ذخیره کنید.
5. دکمه‌ها به‌طور پیش‌فرض خنک/گرم/چهار فصل‌اند؛ هر دکمه یک ترم دارد و از ردیف‌های ویجت قابل ویرایش است.
6. استایل: تب Style ویجت ← رنگ/حاشیه/سایه در سه حالت «عادی»، «هاور» و «فعال»، چینش، فاصله، گردی گوشه و سرعت انیمیشن. هاور فقط روی دکمه‌های غیرفعال اعمال می‌شود (متن، پس‌زمینه، حاشیه، سایه و بالا آمدن). پیش‌فرض‌ها: دکمهٔ سفید، فعال طلایی `#d7b56a`.

## نکته‌ها

- اگر کانتینر والد برای بالا کشیدن دکمه‌ها روی ردیف عنوان margin منفی دارد (مثل صفحهٔ اصلی آرومیست: `-6rem` در دسکتاپ)، margin تبلت و موبایل آن را صفر کنید؛ وگرنه روی عنوانِ چندخطی می‌افتد.
- شناسه یا CSS ID کاروسل باید در **همان سند (صفحه)** باشد؛ فیلتر و کاروسل در دو سند جدا (مثلاً هدر و صفحه) پشتیبانی نمی‌شود.
- شناسهٔ داخلی المنتور (همان `data-id` هفت‌حرفی) هم به‌جای CSS ID قبول می‌شود.
- بدون شناسه، فیلتر روی اولین Loop (`loop-carousel` یا `loop-grid`) هم‌ردیف خودش اعمال می‌شود.
- اگر ترکیبی محصولی ندارد، پیام «محصولی با این ویژگی پیدا نشد» (از ویجت قابل ویرایش) نشان داده می‌شود.
- در ادیتور المنتور تعاملِ AJAX غیرفعال است؛ برای دیدن آن صفحه را در سایت باز کنید.
