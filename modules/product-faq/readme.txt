Contributors: سبحان پارسامهر
Requires at least: 6.4
Requires PHP: 7.4
Stable tag: 1.1.0

بخش «سوالات متداول» برای محصولات ووکامرس: سوالات پیش‌فرض برای یک سری محصولات، سوالات اختصاصی برای بقیه.

== سوالات پیش‌فرض — محصولات ← سوالات متداول ==

* سوال‌ها و جواب‌های پیش‌فرض (کشیدن برای ترتیب، HTML ساده در جواب).
  {product} در سوال یا جواب با نام همان محصول عوض می‌شود: «ماندگاری {product} چقدره؟»
* پیش‌فرض‌ها برای کدام محصولات؟
  - همه‌ی محصولات
  - فقط دسته‌های انتخاب‌شده (و زیرمجموعه‌هایشان)
  - هیچ‌کدام، مگر محصولاتی که خودشان «سوالات پیش‌فرض» را انتخاب کنند
* باکس «جواب سوالت رو پیدا نکردی؟»: عنوان، متن، دکمه و لینک (بدون لینک، دکمه نمایش داده نمی‌شود).

== هر محصول — باکس «سوالات متداول محصول» در صفحه‌ی ویرایش ==

«سوالات این محصول»:
* خودکار (پیش‌فرض): اگر محصول سوال اختصاصی داشته باشد همان‌ها؛ وگرنه سوالات پیش‌فرض، اگر محصول در محدوده‌ی بالا باشد.
* سوالات پیش‌فرض: همیشه پیش‌فرض‌ها (حتی بیرون از محدوده).
* فقط سوالات اختصاصی این محصول.
* سوالات اختصاصی + پیش‌فرض: اول اختصاصی‌ها، بعد پیش‌فرض‌ها.
* نمایش داده نشود.

زیرش نوشته می‌شود الان دقیقاً چه چیزی نمایش داده می‌شود. سوالات اختصاصی با عوض کردن حالت پاک نمی‌شوند.

چند محصول با هم: فهرست محصولات ← انتخاب ← کارهای دسته‌جمعی: ویرایش ← «سوالات متداول».
ستون «سوالات متداول» در فهرست محصولات نشان می‌دهد هر محصول چه چیزی نمایش می‌دهد (اختصاصی / پیش‌فرض / —) و چند سوال.

داده: متای `_tpfq_items` (سوالات اختصاصی) و `_tpfq_mode` (حالت) محصول، و گزینه‌ی `tpfq_settings`.
پلاگین Duplicate Post هر دو متا را همراه محصول کپی می‌کند.

== نمایش ==

ویجت المنتور «سوالات متداول محصول (تکپینو)» را در قالب Single Product بگذارید
(پیشنهاد: بین «توضیحات تکمیلی» و «نظرات»، مستقیم داخل ستون اصلی و نه داخل یک کانتینر جدا؛
چون ویجت برای محصول بدون سوال هیچ چیزی چاپ نمی‌کند، حتی عنوانش).

* برای لینک دادن از منوی «فهرست» بالای صفحه: در تب «پیشرفته»ی ویجت، CSS ID را مثلاً `tab-faq` بگذارید.
  دقت کنید که آن آیتم منو در محصولاتِ بدون سوال به جایی اشاره نمی‌کند.
* در ویرایشگر، اگر محصولِ پیش‌نمایش سوالی نداشته باشد، چند سوال نمونه نشان داده می‌شود (فقط در ویرایشگر).
* فیلدهای باکس «جواب سوالت رو پیدا نکردی؟» در ویجت اگر خالی بمانند از تنظیمات کلی پر می‌شوند.
* موبایل: پلاگین «موبایل آرومیست» (۰.۶.۰ به بعد) همین سوال‌ها را بعد از «معرفی کامل عطر» نشان می‌دهد
  و ویجت المنتور را در موبایل پنهان می‌کند.

شورت‌کد (جاهای دیگر):

[tp_product_faq]
[tp_product_faq id="123" title="سوالات متداول {product}" open="none" single="no" numbers="no" card="no" schema="no"
 cta="auto|yes|no" cta_url="/contact/" cta_title="..." cta_text="..." cta_button="..."]

== سبکی ==

* بدون هیچ فایل جاوااسکریپتی در سایت: آکاردئون با <details> خود مرورگر کار می‌کند.
* فقط یک فایل CSS کوچک، و فقط در صفحه‌ی محصولاتی که سوال دارند (در <head>، بدون پرش ظاهر).
* اسکیمای FAQPage (JSON-LD) یک بار در پایین صفحه. برای خاموش کردن کامل:
  add_filter( 'tpfq_print_schema', '__return_false' );
* با ذخیره‌ی تنظیمات، کش LiteSpeed پاک می‌شود.

== نکته ==

حذف پلاگین سوال‌های ذخیره‌شده را پاک نمی‌کند؛ با نصب دوباره برمی‌گردند.
